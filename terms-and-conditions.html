2. Service Description

Messliner provides an automated dining and mess accounting software platform. Our tools allow shared mess residents, bachelor accommodations, and hostels to:

  • Log daily member meal selections (breakfast, lunch, dinner).
  • Automatically compute real-time Bazar Ratio (Meal Rate) (`Total Bazar Expenses ÷ Total Meals`).
  • Maintain transparent member deposit ledgers and personal balance calculations.
  • Authenticate securely using Supabase Auth with email verification and Forgot Password OTP codes.
  • Receive real-time push notifications (OneSignal/FCM) and optional automated cash deposit confirmation SMS alerts on mobile numbers when enabled by Mess Managers.

3. Mess Roles & Responsibilities

Messliner uses role-based access control to enforce operational transparency:

  • Mess Manager Responsibilities — Managers are required to enter accurate bazar expense entries, upload verifiable purchase receipts, record member cash/mobile banking deposits promptly, and configure SMS deposit notification settings responsibly.
  • Member Responsibilities — Members must enter or update their meal choices before daily manager deadlines, inspect personal balance ledgers regularly, and maintain valid email/mobile details for OTP and deposit SMS receipts.

5. Mobile Application, OTP & Communication Terms

The Messliner Android Mobile Application is built using Flutter and operates as a native WebView wrapper.

Authentication & Email OTP: Account registration and password recovery ("Forgot Password") use Supabase Auth to send transactional emails and 6-digit OTP verification codes. By initiating account setup or password resets, you consent to receiving these transactional authentication emails.

Push Notifications & Cash Deposit SMS: The app integrates OneSignal for push alerts. Furthermore, when a Mess Manager enables the Deposit Confirmation SMS setting in the admin panel, cash deposits logged for a user will trigger an automated transactional SMS receipt sent to the member's registered mobile number.
